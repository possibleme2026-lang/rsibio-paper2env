# Review notes

- Data substitution: the paper's MD ensemble and mutational scans are not redistributable, so the environment ships a deterministic synthetic-but-realistic surrogate generated at image build time (environment/data/gen_at1r_data.py, seed 20260801): 1500 temporally correlated frames x 359 AT1R residues of local interaction energies (kcal/mol) drawn from a sparse Gaussian graphical model with planted allosteric backbone paths from the AngII site through the cryptic intracellular pocket to the G-protein interface, plus a whole-receptor mutscan table whose mean_ddg is partly driven by network centrality. File sizes are realistic (~2 MB npy, 359-row TSVs).
- Method substitution: the paper uses a discrete Bayesian network over binned residue energies; we specify the Gaussian/conditional-independence analogue (Ledoit-Wolf-shrunk inverse correlation -> partial correlations) because it is exactly reproducible and is the canonical estimator implemented by scikit-learn. Everything the grader checks is recomputed by the grader itself with that specification.
- Shortcut probe considered: (a) reading the planted graph out of the visible generator only works for the public split, so 65% of the reward comes from re-running the agent's /app/analyze.py on a held-out ensemble built from a protected seed that never appears in the agent-visible image; (b) hard-coding the public answers fails the same held-out run; (c) tampering with /app/data is useless because the reference answer is recomputed from the data actually present (and the held-out data is generated inside the verifier).
- Tool chain: numpy/scipy/pandas, scikit-learn (ledoit_wolf, the ground-truth shrinkage estimator), networkx (greedy_modularity_communities, single_source_dijkstra), scipy.stats.hypergeom. No domain tool is reimplemented in the grader: the grader calls the same canonical libraries.
- Grader depth: tests/grade.py (~440 lines) recomputes the full pipeline (partial correlations, thresholded network with sequence separation, weighted degrees, z-scored hotspot ranking, greedy-modularity communities + modularity, 12x18 Dijkstra pairwise paths with deterministic tie-breaking, hypergeometric pocket enrichment) and scores seven independently-checkable constraints with continuous partial credit on both the public outputs and the held-out re-run.
- Known limitations: energies are Gaussian and stationary, so no non-linear or non-Gaussian coupling is present; the ligand/NAM virtual-screening step of the paper is intentionally out of scope because it is not deterministically gradeable. Community ids from greedy modularity are checked structurally (valid partition, count range, modularity ratio) rather than by label so that Louvain-style solutions also pass.
- Reproducibility: both the environment generator and tests/gold_gen.py are byte-identical in their construction logic; the public reference is recomputed from the shipped /app/data files when they exist and from gold_gen otherwise, so generator drift cannot penalise a correct solution.
