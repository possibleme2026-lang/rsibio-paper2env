# Review notes

- Data is synthetically generated by environment/data/gen_assays.py with seed 42 to match realistic assay sizes (30 assays, 80-120 compounds each, 100 training proteins, 5 selectivity assays).
- Shortcut probe: the agent cannot read hidden gold because the grader recomputes metrics from the same input data; no test labels are hidden. The challenge is correct implementation of sequence alignment, metric computation, and aggregation.
- Tool chain: Biopython PairwiseAligner for sequence identity, scipy.stats.spearmanr, sklearn MAE, pandas.
- Limitations: synthetic data may not capture all biological complexity; sequence identity threshold and alignment parameters are fixed.
