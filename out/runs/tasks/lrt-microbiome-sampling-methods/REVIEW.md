# Review notes

- Data substitution: the paper's raw sequences are not public, so a deterministic synthetic ASV table (400 ASVs x 105 samples = 99 participant samples from 33 participants plus 6 negative controls) is generated by environment/data/gen_inputs.py with seed 20260802. The generator is executed during the image build and then deleted, so the latent design (which ASVs are reagent contaminants, which ASV is the brush-specific Sphingomonadaceae indicator) is never readable by the agent. The generator is preserved in env_files for the compiler, and the grader re-derives its reference answer from the generated tables in /app/data rather than from a stored gold file.
- Shortcut probes considered: (a) reading the generator - blocked by deleting it at build time; (b) reading the gold answer - there is no gold file in the image, the grader lives in /tests which is mounted only at verification; (c) hard-coding the report - the Sphingomonadaceae ASV id, the retained-ASV set in filtered_asv_table.tsv, and the numeric PCoA/PERMANOVA values (checked to +/-0.03 against a reference re-computation, and the filtered counts must equal the input counts) cannot be guessed without actually running the pipeline.
- Tool chain: numpy/pandas/scipy/statsmodels/scikit-bio are installed in the image. scikit-bio supplies the canonical beta-diversity, PCoA and PERMANOVA implementations and is used by both the agent-facing instructions and the grader. No canonical Python implementation of Dufrene-Legendre IndVal exists (the reference implementation is R indicspecies::multipatt), so the exact IndVal formula and permutation scheme are pinned in the instruction instead of being left to a package; the pinned definition is the Dufrene-Legendre one.
- Determinism: Bray-Curtis, PCoA and PERMANOVA R2 are permutation-free and are compared to the reference with a 0.03 tolerance; permutation p-values are only used through thresholds (p<=0.01, adjusted p<0.05, p>=0.05), which are insensitive to permutation-seed differences between scikit-bio versions.
- Seed validation: the cancer-status PERMANOVA on a null dataset is expected to be non-significant (E[p]~0.4) and the BH-adjusted differential-abundance count is expected to be 0. If a compiler re-run of gen_inputs.py yields a gold cancer PERMANOVA p < 0.05, bump SEED in gen_inputs.py (the grader also falls back to matching the gold count when the gold count is non-zero, so the task degrades gracefully rather than being unachievable).
- Known limitations: SPIEC-EASI co-occurrence network mapping and the 17-node module from the paper are not reproduced (they would require an R/SpiecEasi toolchain and are not needed to reach the difficulty bar); host-derived sequence filtering is represented by the negative-control decontamination step only; the cohort is synthetic but mirrors the paper's 8 cancer / 25 non-cancer design and its 3 sampling methods.
