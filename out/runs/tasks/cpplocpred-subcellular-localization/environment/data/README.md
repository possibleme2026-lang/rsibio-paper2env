# CPPLocPred Synthetic Dataset

This dataset was synthetically generated to mimic the subcellular localization classes used in the CPPLocPred paper.

- train.csv: 1216 sequences with labels.
- val.csv: 305 sequences with labels.
- test.csv: 500 sequences without labels.

Sequences are peptides of length 5-30 amino acids. Localization classes: Cytoplasm, Nucleus, Mitochondria, Endo_lysosome, Others.
