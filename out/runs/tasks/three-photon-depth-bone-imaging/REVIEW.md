# Review notes

- Data substitution: the paper's raw 2P/3P stacks are not public. A deterministic phantom renderer (environment/data/gen_inputs.py, seed 20260731) creates realistic 16-bit multi-page TIFFs: 512x512x24 osteocyte stacks at 0.2 um/px (~12.6 MB each) and 128x128x24 PSF-bead stacks at 0.1 um/px, with depth-dependent attenuation (decay lengths 40 um for 2P and 190 um for 3P), depth-dependent PSF broadening, depth-dependent autofluorescence background and Gaussian read noise. The generator is deleted from the image after the build step that writes the data.
- Shortcut probes considered: (a) the agent could read the generator - it is removed from the image, and the grader additionally re-renders the phantom from the protected seed in tests/gold_gen.py and refuses to score if the on-disk TIFFs are not byte-identical; (b) the agent could hardcode a plausible depth curve - the grader compares each of the 48 rows and the fitted attenuation coefficients against independently recomputed gold with tight relative tolerances; (c) the agent could use the full 0-230 um range for the attenuation fit - constraint 6 explicitly limits the fit to 0-120 um and the grader refits both ways to detect this.
- Tool chain: the image ships libtiff-tools (tiffinfo/tiffdump) for TIFF inspection plus the canonical scientific-Python stack (numpy, scipy, pandas, tifffile, scikit-image). All metric definitions are pinned in the instruction so the grader can use exact recomputation rather than a hand-wavy comparison. Depth-plane artifacts beyond ~160 um (2P SNR collapses to zero) force the agent to handle the signal-free branch and the non-monotone/monotone edge cases.
- Known limitations: the phantom models attenuation as a single exponential per modality and uses depth-independent Gaussian read noise (real detectors are shot-noise limited); the axial PSF is not modelled, so only the lateral FWHM is scored; the bead second-moment estimator is slightly biased low (a few percent) at the deepest 2P plane because of the b+3*sigma weight threshold - this bias is identical for the reference and the agent because the estimator is fully specified.
