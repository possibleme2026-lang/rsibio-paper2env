# Review notes

- Data substitution: the original paper uses the Boltz2ESI co-folding foundation model; here we substitute a deterministic co-folding-inspired feature-based ridge surrogate using RDKit descriptors, active-site pocket features, k-mer JSD, and Tanimoto similarity. The task tests the same multi-step structural/chemical complementarity reasoning without requiring model weights.
- Shortcut probe: the gold predictions are never written to the agent-readable environment. The grader recomputes gold from pristine inputs generated by a hidden copy of the input generator (tests/input_gen.py) and a reference implementation (tests/gold_gen.py) that lives only in the verifier phase.
- Tool chain: RDKit for molecular descriptors and Morgan fingerprints, NumPy/Pandas for data handling, SciPy for Spearman correlation. All are installed in the Docker image.
- Known limitations: enzyme sequences and substrates are synthetic but realistic in size and composition; the reference interaction scores are generated by a simple deterministic function to provide training data, so the ranking task is about correctly implementing the specified pipeline rather than discovering novel biology.
