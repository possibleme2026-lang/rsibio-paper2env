# Review notes

- Data substitution: no patient-derived data is used. environment/data/gen_inputs.py deterministically synthesises clinical.tsv (27 patients, 13 established organoids), common_snps.tsv (600 germline loci) and 12 WES call tables (280-480 rows each) from seed 20260802; the Dockerfile runs the generator at build time and tests/gold_gen.py embeds the identical generator so the grader can rebuild the same bytes.
- Shortcut probe: the published numbers (48.1% establishment, HR=13.91, p=0.0039) are deliberately NOT reproduced, so copying paper values fails. The visible generator emits raw rows but never writes the post-filter intersection, the Jaccard values or any statistic: the 7% sub-threshold rows, the 5% extra failing rows and the germline copies all change the filtered sets, so re-running the generator still leaves the filtering, the locus intersection and the survival analysis to be implemented.
- Shortcut probe (tampering): the grader regenerates the whole dataset from the protected seed and requires /app/data to be byte-identical, so editing the inputs to make the analysis trivial invalidates the run (score 0).
- Tool chain: numpy / scipy / pandas / lifelines are installed; lifelines is the canonical implementation used for the Cox model, the log-rank test and the Kaplan-Meier medians, and scipy supplies the two-sided Fisher exact test and the Spearman correlation. The grader falls back to a self-contained Breslow Newton-Raphson Cox fit and a hand-rolled log-rank test if lifelines cannot be imported or fails to converge.
- Known limitations: the cohort is small (13 established organoids, 5 solid), so the Cox hazard ratio has a wide confidence interval; the HR and log-rank checks are therefore tolerance-based (20% / 25% relative) instead of exact, and partial credit is granted per constraint. The variant tables are TSV rather than VCF to keep filtering semantics and grading fully deterministic across tool versions. Patient PFS times were hand-assigned to give overlapping groups (solid 4.2-35.6 months, cystic 8.1-57.3 months) so that the Cox partial likelihood has a finite interior maximum.
