# Review notes

- Data substitution: real Hi-C libraries cannot be redistributed, so the benchmark uses sparse count matrices (2 resolutions x 4 replicates x 8 depths x 3 subsamples = 192 files) generated by a deterministic Poisson subsampling model (window/loop/compartment/domain structure, seed 20260728). The generator runs at image build time and is deleted from the image, so the agent only sees the matrices; the verifier holds its own copy (tests/gold_gen.py).
- Shortcut probe: the thresholds published in the paper's abstract (about 10/20/30/60 M read pairs) are deliberately NOT the answer for this simulated dataset and are never stated in the instruction. Hard-coding them, or guessing grid values, fails ~75% of the weight: the per-depth metric curves, the scatter curves, the replicate variability, the boundary F1 and the PC1 correlation all require recomputing the metrics from the raw matrices, and the threshold checks require the values to agree within one grid step of the reference derived from the data.
- Tool chain: numpy/scipy only. The five metrics are defined analytically in the instruction (P(s) log-derivative loop bump, diamond-window insulation with median normalisation, greedy boundary calling, O/E row-correlation PC1). No canonical Hi-C package implements exactly these conventions (cooltools uses different normalisation and boundary filters), so the grader recomputes them from the matrices rather than shelling out to a tool; the instruction warns the agent about this explicitly.
- Known limitations: the absolute depth thresholds depend on the simulation's noise model and on the number of replicates (4) and subsamples (3); loop metrics are evaluated at 100 kb resolution so loop_size_kb is quantised to 100 kb steps; the ordering constraint is checked against the reference ordering when the reference itself is not strictly paper-ordered.
- Determinism: both the generator and the verifier use fixed seeds and closed-form aggregations; the grader writes {'score': ..., 'reward': ...} to /logs/verifier/reward.json.
