# Review notes

- Data substitution: the paper's raw images, plate files and subject data are not public, so a deterministic synthetic cohort (seed 20260802, environment/data/gen_inputs.py, run at image build time) reproduces the study's design - 21 fertile controls vs 79 infertile women, ~18,000 segmented microscopy objects across 3-8 fields per subject, three 96-well TBARS plates with per-plate standard curves and 5 deliberately saturated wells. Effect direction (higher NBT reactivity, higher %NBT-positive neutrophils and higher MDA in infertile women) and correlation structure mirror the published findings; the exact statistics differ and the grader recomputes them from the generated tables.
- Shortcut probes considered: (i) hard-coding the published numbers (r = 0.410, r = 0.510, r = 0.21, P < 0.0001) fails because grading is against values recomputed from the synthetic tables and against per-subject values exact to 0.01-0.10; (ii) re-running gen_inputs.py only reproduces the raw inputs the agent already has; (iii) computing NBT positivity with the 25.0 threshold in pixels instead of um^2 (the pixel size 0.25 um/px is only in assay_parameters.json) is caught by constraint C3.
- Tool chain: no canonical binary exists for NBT formazan quantification, so the ground truth is the standard scientific Python stack installed in the image (numpy, pandas, scipy.stats.mannwhitneyu/spearmanr, sklearn.metrics.roc_auc_score). The grader recomputes the entire gold analysis from /app/data and never reads any derived answer from the task environment.
- Known limitations: the 'novel NBT method' has no published operational definition, so NBT positivity (>= 25 um^2 formazan) and NBT reactivity (mean formazan area per neutrophil) are specified explicitly in the instruction; the MDA/TBARS pipeline is deliberately simplified to a linear per-plate standard curve with a single dilution factor; plate-level pipetting errors, edge effects and sample haemolysis are not modelled.
- Grading: 8 independently checked constraints, score = passed/8 with per-constraint detail printed to stdout and written to /logs/verifier/report.json; /logs/verifier/reward.json contains only {"score": float, "reward": float}.
