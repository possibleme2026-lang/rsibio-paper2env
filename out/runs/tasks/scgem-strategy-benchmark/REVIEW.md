# Review notes

- Data substitution: no real dataset or GEM is redistributed. environment/data/gen_inputs.py deterministically synthesizes the task inputs at image build time (seed 20260802): an 80-cell x 600-gene UMI count matrix with cell-type marker programs, Poisson noise and mean-dependent dropout; a dropout-perturbed copy (10% of non-zeros zeroed); a curated 300-reaction metabolic model with nested AND/OR GPR rules, 20 gene-independent reactions and 8 essential reactions; and bulk-derived per-cell-type reference reaction sets. Files are ~150-250 KB each, i.e. realistic panel scale.
- Shortcut probes considered: (a) copying reference_models.tsv as the per-cell answer fails C2 (mean Jaccard against the recomputed gold models collapses); (b) emitting all-zero or all-one matrices passes C1 but fails C7 (mandatory reactions missing / <5 active) and C2; (c) hard-coding the metrics table without building models fails C2, C3-C5 tolerances are checked per strategy against an independent recomputation; (d) the winning strategy cannot be guessed because the gold metrics are never written into the image.
- Tool chain: the ground truth of this task is the fully specified aggregation algorithm, so no external domain binary is required; numpy 1.26 and pandas 2.2 are the canonical implementation stack and are pinned in the image so that np.percentile linear interpolation is unambiguous.
- Grader depth: tests/grade.py imports tests/gold_gen.py, which re-runs the entire 18-strategy pipeline (GPR parsing, preprocessing, fuzzy vs boolean MEM, per-cell percentile thresholds, 80x80 pairwise Jaccard) from the inputs and then performs per-strategy, per-cell comparisons with seven independently weighted constraints and graded partial credit.
- Known limitations: the composite (0.5*accuracy + 0.3*robustness + 0.2*specificity) and the reference-model construction are simplified stand-ins for the paper's nine-dataset protocol; strategies that threshold exactly at the zero-valued score mode can return near-full models, which is a genuine property of threshold-based scGEM construction and is reproduced identically by the grader.
