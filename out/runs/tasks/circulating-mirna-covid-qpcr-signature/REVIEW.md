# Review notes

- Data substitution: no raw study data are available for this paper, so the plate export, metadata, miRNA-target table and immune panel are produced by a seeded simulator (environment/data/gen_inputs.py, seed 20260802) matching the reported design: 40 mild/asymptomatic cases vs 40 controls, 9 reported miRNAs plus 3 low-detection panel members that must fail the 70% QC filter, two spike-in controls (cel-miR-39-3p, UniSp6), two technical replicates, no-template controls and a realistic Ct range (22-36 Ct).
- Shortcut probe: the simulator contains the true effect sizes, so it is executed during the image build and then deleted (rm -f /app/data/gen_inputs.py) - nothing in the container reveals gold values. Copying the simulation parameters instead of computing them fails, because the grader compares against statistics recomputed from the realised samples (tolerances are 0.02 Ct for dCt and 0.02-0.10 for fold changes, far tighter than the sampling error of the parameters). The hidden answer only exists in tests/gold_gen.py + tests/grade.py, which are mounted at verification time.
- Tool chain: ground truth is statistical, so canonical implementations are called rather than reimplemented - scipy.stats.ttest_ind(equal_var=False) for Welch, statsmodels.stats.multitest.multipletests(fdr_bh) for Benjamini-Hochberg and sklearn.metrics.roc_curve/roc_auc_score for ROC and the Youden point. These are the packages the grader itself uses.
- Determinism: all inputs are regenerated byte-identically from the fixed seed, so gold values are stable; the grader additionally falls back to regenerating the inputs with tests/gold_gen.py if /app/data is not present.
- Known limitations: the synthetic effect sizes were tuned so that the seven reported miRNAs dominate the ROC ranking, but the exact AUCs (and possibly one borderline member of the significant set, miR-21-5p) will differ slightly from the published values. The grader therefore always compares against the recomputed reference signature instead of a hard-coded list, and only enforces the robust paper-level claims (miR-30c and miR-126 must be significant, miR-155 must not).
