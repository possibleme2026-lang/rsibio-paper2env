# Review notes

- Data is synthetic, generated by a deterministic simulator (`gen_data.py`). The simulator is provided in the environment so the agent can generate additional labeled data. The hidden test uses a different seed and larger size (50 compounds, 200 noise features).
- Shortcut probe: agent cannot read hidden labels because they are generated at verification time from a protected seed in `tests/gold_gen.py`. The agent could modify `/app/data/gen_data.py`, but the grader uses its own copy in `tests/`.
- Tool chain: Python 3.11 with numpy, pandas, networkx, scikit-learn, pyteomics. The reference solution uses networkx for graph components and a deterministic neutral-mass voting scheme.
- Known limitations: The task simplifies the GAT to a deterministic graph-based collective inference to ensure reproducibility and fair scoring. The core idea of joint detection and annotation via graph components is preserved.
