# Review notes

- Synthetic data generated by environment/data/gen_inputs.py with seed 42; simulates 3 timepoints, 4 spatial quadrants, 20 genes, and varying spot counts per timepoint.
- Shortcut probe: the reference implementation lives only in tests/gold_gen.py and is not accessible during the solve phase. The input generator does not encode the reference algorithm, so the agent must implement the method from the instruction.
- Tool chain: Python 3.11 with numpy, pandas, scipy, scikit-learn. GraphicalLasso from scikit-learn is used as the canonical graphical lasso implementation.
- Limitations: This is a simplified surrogate of SpaTemGRN; it focuses on the core steps of spatial smoothing, temporal borrowing, and graphical lasso. The metric is AUROC against the hidden reference implementation, which is deterministic given the fixed seeds.
