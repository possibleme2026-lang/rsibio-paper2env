# Review notes

- Data substitution: no public PVG was shipped, so a synthetic-but-realistic GFA 1.0 graph is generated deterministically (SEED=20260731) by environment/data/gen_inputs.py: 118 loci, ~180-200 segments with 80 bp - 2.5 kb sequences and GC-correlated bases, 24 sample paths with +/- orientation tokens, and a complete L-line adjacency between consecutive loci. Two haplotype blocks (loci 45-47 and 83-84) carry a designed case-enriched allele; everything else is null, so the agent must actually run the statistics to recover them.
- Shortcut probe: (a) gen_inputs.py is deleted from the image in the same RUN that generates the data, so the seeded causal design is not readable at solve time; (b) even if it were, the required output is the full per-node table (carrier counts, PS, exact hypergeometric p, monotone BH q, significance) for every segment plus the region decomposition, so knowing which loci carry signal does not yield the answer; (c) the verifier never reads /app/data - it regenerates the graph from its own protected copy of the generator and therefore cannot be gamed by tampering with the input files.
- Tool chain: scipy.stats.hypergeom.sf is the canonical exact one-sided upper-tail test and scipy is installed in the image; the reference solution uses it. gfapy is installed so the agent may parse GFA with a real pangenome library instead of hand-rolling a parser. numpy/pandas are available for the tables.
- Metric: the headline metric is the F1 of the predicted significant-node set against the reference set (the paper reports whether the method recovers the expected phenotype-associated locus); the reward itself is a weighted composite of nine independently verified checks with partial credit.
- Known limitations: the real GRANPA computes its Phenotype Score from the distribution of phenotype labels on node traversals and assesses significance with a resampling scheme; here the association is operationalised as an exact hypergeometric/Fisher test with Benjamini-Hochberg control, which is equivalent in spirit but not byte-identical to the published implementation. Region definition is induced-subgraph connectivity over L lines rather than the published sliding-window smoothing.
- Grader note: tolerance for PS is 2e-6 absolute (values are written with %.6f) and 1e-6 relative for p/q (written with %.6e); the reference node set is regenerated at verify time, so the score is deterministic and reproducible.
