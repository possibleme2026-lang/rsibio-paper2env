# Review notes

- Data substitution: the paper uses 1000 Genomes panels and coalescent simulations, which are not redistributable here. The environment is instead a deterministic Li-Stephens-style simulator (environment/data/gen_inputs.py, seed 20260730, executed at image build time) with paper-appropriate scale: 3000 SNPs over 150 cM, 60 reference haplotypes per source population, 4 admixed haplotypes, and three divergence levels (FST 0.002 / 0.020 / 0.150) calibrated by bisection on the realised frequency-based FST. The same four ancestry paths are reused across levels so only reference divergence varies.
- Shortcut probe: the agent can read the generator and therefore the true switch rate (lambda_true = 40) and the true ancestry paths, but that does not help - the graded artifacts must be the *model's* ML estimate, posteriors, Viterbi path and downstream statistics. The verifier ignores /app/data entirely and recomputes the reference decoder from a protected copy of the simulator in /tests/gold_gen.py, so editing or regenerating the visible data cannot move the gold standard; copying the truth line into the Viterbi output fails the exact Viterbi check.
- Tool chain: python:3.11-slim with numpy/scipy/pandas/scikit-learn and hmmlearn installed, so the agent can drive a real HMM library as long as the specified parameterisation (pseudocount 0.5, initial 0.5/0.5, exp(-lambda d) transition, lambda grid 1..120, ties to A) is honoured. All ground truth is recomputed by the grader, not looked up.
- Grading is fully relational to the grader's recomputation (tolerances on posteriors, exactness on paths, a 0.5-nat likelihood slack on lambda_hat), which keeps the score robust to floating-point variation while still requiring a real scaled forward-backward, Viterbi and grid-search implementation.
- Known limitations: absolute accuracies will not reproduce the paper's exact numbers because the divergence model is a simple frequency shift rather than real 1000G haplotypes, and the admixture-time conversion T_hat = lambda_hat/(2 alpha (1-alpha)) with alpha = 0.5 is the model's own simplification rather than a demographic inference. The tract-inflation diagnostic is therefore defined relative to the same simulated region across levels, not to the paper's 78.8x figure.
