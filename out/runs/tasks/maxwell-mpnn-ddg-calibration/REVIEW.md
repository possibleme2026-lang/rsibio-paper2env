# Review notes

- Data substitution: the real MAXWELL pipeline runs ProteinMPNN (torch weights, GPU) and is evaluated on curated experimental ddG benchmarks (S2648/S669/Megascale). Both are too heavy / not redistributable inside this container, so the task supplies synthetic-but-realistic ProteinMPNN-style L x 20 logit matrices for 12 proteins (128-230 residues, 20 canonical AAs), 3000 labelled training mutations and 840 held-out test mutations. The generative model mirrors the paper's premise: ddG is a monotone function of the matrix-wise log-odds ratio log P(mut|structure) - log P(wt|structure) plus an amino-acid propensity difference term.
- Deterministic generation: environment/data/gen_inputs.py builds every input file from fixed seeds and is executed during the image build; it is then deleted from the image so the agent cannot read the ground-truth generative model (it remains visible to reviewers inside this blueprint). tests/gold_gen.py re-derives the identical logit matrices, sequences, train/test split AND the held-out labels using a private noise seed that never appears in the image.
- Shortcut probe (considered and blocked): (a) reading the test labels - impossible, they exist only in tests/ and are regenerated from HIDDEN_TEST_NOISE_SEED; (b) hard-coding constants - blocked by RMSE/Spearman on 840 unseen mutations whose irreducible measurement noise (sigma = 1.0 kcal/mol) caps the achievable RMSE around 1.0; (c) ignoring the language-model matrix and fitting only mutation-type identity - capped at Spearman ~0.48, below the 0.65 threshold; (d) predicting a constant - Spearman ~0 and RMSE ~1.97, failing both metric constraints; (e) emitting a landscape whose wild-type diagonal is non-zero - fails constraint 6 unless the wild-type residue identity is modelled or the row is anchored.
- Tool chain: numpy / pandas / scipy.stats.spearmanr / scikit-learn (Ridge). No canonical external binary is the ground truth here because the ground truth is the synthetic generative process; scipy.stats is used directly by the grader so the metric is not re-implemented. biopython is installed for FASTA handling.
- Grader depth: tests/grade.py (~300 lines) parses both artefacts, validates row/column schemas, recomputes Spearman and RMSE against regenerated gold, checks the landscape shape and physical range, checks the wild-type diagonal, and cross-checks landscape cells against predictions.csv. Score is a weighted sum of seven independently-checkable constraints; only plain numbers are written to /logs/verifier/reward.json (the full breakdown goes to stdout and /logs/verifier/report.json).
- Known limitations: the container does not run the real ProteinMPNN network, so the task measures the calibration/feature-engineering half of MAXWELL rather than end-to-end language-model inference; absolute ddG magnitudes are synthetic and should not be interpreted biophysically. The reference solution reaches Spearman ~0.85 and RMSE ~1.05, leaving headroom above the 0.65 / 1.60 thresholds.
