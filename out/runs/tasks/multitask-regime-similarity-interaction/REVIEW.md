# Review notes

- Data substitution: the paper's human behavioural data are not openly distributed with the preprint. Inputs are a deterministic synthetic dataset (seed 20250922, 288 participants, ~73.6k trials, ~6 MB CSV) generated at image build time by environment/data/gen_inputs.py, which is deleted from the image after the CSV is written. The generator encodes only the marginal structure needed to make the regime x similarity interaction analysable; exact effect sizes are not the paper's.
- No neural-network replication is required: the paper's model-replication component is not reproducible deterministically across implementations, so the graded task targets the behavioural interaction analysis, which has a unique correct answer once the pipeline is fixed. This keeps scoring deterministic and shortcut-proof.
- Shortcut probe: the latent cell probabilities are never present in the image (generator removed at build), and reporting them instead of the sample estimates fails the 0.005 tolerance because sampling error is ~0.02. The grader also regenerates the dataset from tests/gold_gen.py, so editing /app/data/behavior.csv cannot move the gold answer and is separately penalised by the data_integrity check. The example JSON in the instruction uses placeholder zeros only.
- Tool chain: pandas/numpy/statsmodels/scipy are installed in the image; the grader re-implements the whole pipeline independently (raw CSV -> exclusions -> participant-level cell means -> saturated OLS contrasts) instead of comparing against a stored answer file.
- Deliberate kill-tests: warm-up trials (first 5 of every block) have depressed accuracy, and ~1.3% of trials carry impossible response times with incorrect responses, so skipping E3 or E2 shifts every cell mean well beyond tolerance and changes n_trials_analyzed.
- Known limitations: p-values are checked qualitatively (p_conceptual < 0.01, p_conceptual <= p_spatial) rather than numerically, because small implementation differences in the contrast test are acceptable; the decision flag is checked both against the reference and for internal consistency with the agent's own reported numbers.
- Bounds were calibrated so the reference statistics are stable under the fixed seed: the conceptual-first interaction is large (roughly 0.2 in accuracy units, t > 4) while the spatial-first interaction is near zero, so the order-asymmetry decision does not flip under sampling noise.
