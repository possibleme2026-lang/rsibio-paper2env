# Review notes

- Data substitution: the real TCGA beta matrices and the published 353-CpG Horvath coefficient table cannot be redistributed here, so environment/data/gen_inputs.py deterministically synthesises a 960-sample x 550-probe cohort (8 cancer types x 60 patients, matched tumour/normal) plus a synthetic 353-probe 'MT-clock' coefficient set at build time. The generator is deleted from the image after the build so the agent only sees the resulting TSV/CSV/JSON inputs.
- Tumour-versus-normal age shifts are planted in the latent clock predictor (UCEC/LUSC/HNSC/PRAD positive, KIRC/THCA negative, BRCA/COAD null) so that the reference Wilcoxon + Benjamini-Hochberg analysis reproduces the paper's directional pattern; the direction of these effects is not observable from the input files without running the full pipeline.
- Shortcut probe considered: an agent could try to skip the clock and guess the affected cancer types from the metadata, or skip the tree and only report event counts. The grader defeats the first by requiring the numeric MAE and per-type median deltas (which depend on correctly applying the piecewise transform and the one_minus_beta probe flips) and the second by parsing the eight Newick files and checking clade topology plus branch lengths against the hidden linkage.
- Tool chain: numpy/scipy (Wilcoxon signed-rank, hypergeometric, pdist/linkage/cophenet), pandas, statsmodels and Biopython are installed; no domain ground-truth binary is reimplemented in the grader - the grader re-runs the same scipy primitives as a protected reference.
- Known limitations: the 'phyloepigenetic tree' is built across patients within a cancer type rather than across multi-region samples of a single tumour, because the synthetic cohort has one tumour sample per patient; chrX is deliberately over-represented in the 550-probe panel (6.5% instead of the ~2.4% of a 450K array) so that the enrichment test is estimable at this panel size. Both choices are documented here and do not affect the checkability of any constraint.
- Determinism: every stochastic step uses numpy default_rng(20260729); the clock coefficients are rounded to 6 decimals before the intercept is derived, so the gold recomputation is bit-stable across runs of the same image.
