# Review notes

- Data substitution: the UPENN-GBM / HCP / MNI152 cohort cannot be redistributed, so `environment/data/gen_inputs.py` deterministically synthesises six tumour-host pairings. Each host has a 40x40x40 grid, a three-bundle white-matter geometry, a multi-shell DWI built from a mixture-of-tensors forward model (3 x b=0, 20 x b=1000, 22 x b=2000) with Rician noise at SNR ~30, and reference masks produced by running the same SHORE + streamline pipeline with a held-out per-pairing parameter set, then perturbed (1-voxel dilation with 22% boundary dropout) to mimic segmentation noise. The full 1950-pairing cohort is scaled down to 6 pairings so the whole workflow runs in minutes.
- Shortcut probe considered: (a) writing the reference mask straight into `occupancy/` - blocked by the exact-copy, >0.4% voxel-difference and Dice<0.99 checks, plus the streamline-rasterisation consistency check which requires streamlines that geometrically satisfy step-length, turn-angle and in-brain constraints and that re-rasterise to the reported occupancy; (b) skipping the fit and hard-coding parameters - blocked by the curriculum log, the per-pairing parameter-bound check and the Dice floor; (c) faking `comparison.json` / `comparison_dodf.json` - blocked because the isotropic and single-tensor metrics are recomputed from the corresponding occupancy maps rather than trusted from JSON. The input generator itself is deleted at the end of the image build so that the held-out generation parameters are not readable at solve time.
- Tool chain: numpy 1.26.4, scipy 1.11.4, nibabel 5.2.1 and DIPY 1.9.0 (real domain package) provide the ODF reconstruction (`dipy.reconst.shore.ShoreModel`, `dipy.reconst.dti.TensorModel`) and NIfTI I/O; the streamline propagator itself is the object of the task, in the same way the original study drives MRtrix3 iFOD2 from a reconstructed dODF.
- Known limitations: the reference masks are generated by the same propagation family the agent implements, so the achievable Dice ceiling (~0.85-0.9) is set by RNG differences and the boundary perturbation rather than by a real imaging-to-simulation transfer gap; the paper additionally reports MRtrix3-specific iFOD2 second-order stepping and a five-metric constrained optimiser that are simplified here to a single-step propagator and a weighted-sum objective; no real MRtrix3 binary is installed because the task asks for the simulator, not the tractography CLI.
- Determinism: gen_inputs.py is seeded (20260730), the grader never re-runs the agent's solver, and every threshold is a fixed constant, so scores are reproducible.
