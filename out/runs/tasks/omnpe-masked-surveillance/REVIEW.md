# Review notes

- Data substitution: the paper's Zika (French Polynesia) and Xylella (Apulia) datasets are not openly redistributable. The environment ships a deterministically generated effective-SEIR analogue with six archipelagos (312 weekly rows, 30-49 reported weeks each), a population table, and a 250-region simulation library with known R0. The generator (environment/data/gen_inputs.py) runs at image build and is deleted in the same layer, so the hidden generating R0 values are not present in the running container.
- Tool chain: scipy.integrate.solve_ivp + scipy.optimize.least_squares are the ground-truth ODE/fitting tools (the grader compares against the same ODE semantics); scikit-learn is available for the amortised surrogate. Nothing domain-specific is reimplemented in the grader.
- Shortcut probe: (a) writing a constant R0 for all regions is penalised because the true R0 values span 1.55-2.90 and the recovery check is graded (1.0 within 15%, 0.5 within 30%); (b) a constant R0 predictor on the amortisation metric also loses because the holdout R0 spans 1.5-3.0 and credit is graded at 15/25/40%; (c) reading the generator to recover the truth is blocked because gen_inputs.py is removed at build time; (d) the amortised holdout features and their true R0 live only in tests/gold_gen.py.
- Grading: seven independent constraint groups with explicit weights summing to 1.0; reward.json contains only {'score': float, 'reward': float} and the per-constraint breakdown goes to stdout and /logs/verifier/report.json.
- Known limitations: the SEIR observations are deterministic-ODE-plus-lognormal-noise rather than a stochastic compartmental simulator, and the amortised surrogate operates on hand-specified summary statistics rather than a learned normalizing flow, so this is a methodological analogue of OM-NPE rather than a reimplementation of the paper's neural posterior estimator. Absolute R0 tolerances (15%/30%) were chosen from the signal-to-noise ratio of the generator (6% multiplicative observation noise).
