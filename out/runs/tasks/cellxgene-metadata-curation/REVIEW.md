# Review notes

- Data substitution: the paper is a perspective on the collaborative submission model of CZ CELLxGENE Discover and contains no dataset or algorithm. The operational core of that model - curator-driven conversion of an unstandardised contributor deposit into schema-validated, ontology-annotated metadata - is turned into a concrete curation task. All inputs are synthetic but structurally realistic (60 donors, ~1,300 cells, 532 gene rows incl. versioned/duplicated Ensembl IDs, ~250k-entry MatrixMarket count matrix, free text with case/whitespace/synonym variants and unresolvable sentinels).
- Synthetic vocabularies: ontology tables are curated subsets with plausible but not guaranteed-authoritative CURIE/label pairs (real CL/UBERON/EFO/NCBITaxon/MONDO/PATO/HsapDv/MmusDv namespaces). Because of this, the canonical cellxgene-schema validator is deliberately NOT used as the ground truth; the grader re-implements the stated rules. Python/numpy/pandas/scipy are installed so the agent can parse the MTX/matrices with real tooling.
- Shortcut probe: the deterministic generator ships inside the image (transparency/regeneration) but stores NO canonical answer key - every canonical value is recoverable only by resolving the rendered string against the vocabulary tables, which is exactly the intended work. Gold is recomputed by tests/gold_gen.py, which contains its own copy of the generator and rebuilds the submission from the protected seed, so tampering with /app/data cannot influence scoring. Reading the generator therefore yields the same information as reading the inputs.
- Determinism: all generation and gold computation use Mersenne-Twister with fixed seed 20260602 and a fixed call order; the generator body in tests/gold_gen.py is a byte-for-byte copy of environment/data/gen_inputs.py. Divergence between the two copies would be the main maintenance risk.
- Limitations: cell counts are downsampled relative to a real CELLxGENE deposit (10^4-10^6 cells); disease/developmental-stage ontologies are simplified; the eval rewards rule compliance against one specific curation policy rather than biological truth.
