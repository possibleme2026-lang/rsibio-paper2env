# Review notes

- Data substitution: the real cohort (87 subjects, 55 MPN / 32 non-MPN, Olink-style NPX) is replaced by a deterministic synthetic cohort of 96 subjects (approx. 60 MPN / 36 non-MPN; 64/32 train/test split) with 44 plasma proteins, ~3% missing values, three assay plates with per-plate offsets and realistic blood-count covariates. The synthetic effect sizes follow the paper's findings (hemostasis/platelet proteins elevated in MPN, PV-specific TFRC/SEMA7A/EPOR, IL6 dependent on JAK2 status rather than on MPN status).
- Shortcut probe: the withheld diagnoses never appear in the container. The data generator is executed in a builder stage and only the CSV files are copied into the final image, so re-running or reading the generative code is impossible for the agent; the protein list that carries the true signal is therefore not recoverable. A CBC-only classifier is deliberately kept weak (referral cohort with overlapping blood counts), so the proteome must be used.
- Tool chain: numpy/pandas/scipy/sklearn (Welch t-test, Benjamini-Hochberg, L1-penalised logistic regression with stratified 5-fold CV). No bespoke reimplementation of the statistics is required; the grader recomputes gold with the same deterministic generator and rank-based AUC.
- Grader: 11 independent pass/fail constraints, score = fraction passed; the reward file contains only numbers and the per-constraint detail is written to stdout and /logs/verifier/report.json.
- Known limitations: the synthetic proteome has simpler correlation structure than a real PEA panel (no assay-specific LOD curves, no sample-preparation covariates beyond plate); the TFRC AUC check uses a 0.10 tolerance to absorb differences in imputation and batch handling.
