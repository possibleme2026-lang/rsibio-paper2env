# Review notes

- Data substitution: no HpaBC variant table is public, so the whole dataset (FASTA, 220 single mutants, 56 DE multi-mutants, 11,514 zero-shot scores, 64 held-out designs) is synthesized by environment/data/gen_inputs.py under a public seed; the paper's protocol (single-mutant seeded combinatorial design plus zero-shot ML scoring) is preserved. The FASTA sequence is a realistic 606-aa stand-in, not the deposited HpaBC sequence.
- Hidden ground truth: the held-out assay values are produced only by tests/gold_gen.py, which re-derives the public dataset from the shared public seed and then adds protected-keyed epistasis, unseen-substitution residuals and assay noise. Nothing in the container can reproduce those values, and re-running the shipped generator only reproduces the measurements the agent already sees.
- Shortcut probe considered: an agent could try to read the generator and back out the latent per-mutation effects; this is useless because the held-out value of a measured substitution is defined as the shipped (noisy) measurement itself, and all remaining components are keyed by strings that live only in tests/. Peeking at /tests is impossible during the solve phase. A second probe, fitting pairwise epistasis from de_variants.csv, transfers poorly because the shipped DE interactions use a different key than the held-out designs (this is intended and is visible as a CV degradation for interaction-heavy models).
- Tool chain: python:3.11-slim with numpy/scipy/pandas/scikit-learn; no domain binary is required because the ground truth is a statistical model, and the grader recomputes the baseline itself rather than trusting agent-reported numbers.
- Limitations: accuracy thresholds are relative to a zero-shot-only baseline computed by the grader so that the task stays solvable without tuning against a hidden absolute scale; the exact achievable Spearman depends on how many held-out design substitutions are covered by the DE library (~70%). All grading is deterministic given the generator.
