# Review notes

- Data substitution: the original DOC cohort (CNT/MCS/UWS resting-state fMRI, ~100 ROIs x 300 volumes) is not public, so a synthetic cohort with realistic structure and size is generated deterministically (seed 20260730) by environment/data/gen_inputs.py: VAR(1) BOLD time series with four recurrent coordination regimes (one of them hyper-hierarchical with elevated fronto-thalamo-insular trophic levels), group-dependent state dwell times, group-dependent coupling-to-noise ratio, and CRS-R scores partially driven by the subject's fronto-thalamic hierarchical strength. 45 subjects x 41 windows x 100 ROIs, ~12 MB of CSV.
- Paper fidelity: phase-coupling time-resolved connectivity is operationalised as a band-limited lag-1 ridge effective-connectivity estimate plus a fixed edge-density threshold, so that every step of the pipeline is exactly reproducible by the grader; the trophic-level definition, trophic incoherence F0, state occupancy/dwell time and metastability/synchrony definitions follow the trophic-coherence literature used by the paper.
- Grader design: tests/gold_gen.py regenerates the cohort from the protected seed and re-runs the reference implementation; the agent never sees the gold. 16 independently scored checks with partial credit (schema, structure, group statistics, orderings, CRS-R rank correlations, top-20 anatomical list, per-subject agreement).
- Shortcut probe considered: because group labels are visible in subjects.csv, an agent could try to fake group statistics by hand; this is defeated by per-subject agreement checks, the anatomical top-20 list and the exact structural parameters (1845 windows, cluster criterion), none of which can be guessed. Tampering with /app/data is useless because the grader regenerates the cohort from the seed inside tests/.
- Tool chain: numpy 1.26.4, scipy 1.11.4 (Butterworth/filtfilt/Hilbert, Spearman), scikit-learn 1.4.2 (KMeans); no external binaries are needed because the ground truth here is a specified numerical pipeline rather than a canonical CLI tool.
- Known limitations: the synthetic regimes are cleaner than real DOC dynamics, so recovered occupancies are more separated across groups than in a clinical cohort; the k-means solution is deterministic given the specified preprocessing, and the grader uses tolerances (occupancy +/-0.06, correlations +/-0.12) to absorb floating-point and CSV-rounding differences.
