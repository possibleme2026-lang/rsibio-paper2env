# Review notes

- Synthetic data generated by environment/data/gen_inputs.py with seed 42. 200 patients, 5-15 irregular visits, 12 biomarkers, latent double-well diffusion.
- Shortcut probe: agent could read gen_inputs.py and use the true latent x, but the task requires TICA on observed biomarkers, which is not the true latent.
- Tool chain: numpy, pandas, scipy, scikit-learn for TICA and AUC.
- Known limitations: TICA assumes linear RC; the synthetic data includes nonlinear biomarker relationships, so the optimal linear RC is an approximation. The grader recomputes gold from the same input CSV using the reference implementation.
