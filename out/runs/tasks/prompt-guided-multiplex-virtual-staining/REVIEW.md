# Review notes

- Data substitution: the JUMP/in-house multiplex microscopy data of the paper are proprietary and far too large for a container, so a deterministic multiplex-fluorescence simulator (environment/data/gen_inputs.py, ~9 elliptical cells per 160x160 field, six channels, Poisson-free Gaussian sensor model) generates realistic-looking train/valid/test stacks. The same simulator is duplicated inside tests/gold_gen.py so that the verifier regenerates every scored array itself instead of trusting files the agent can edit.
- Shortcut probes considered: (a) calling the shipped renderer - defeated because gen_inputs.py is deleted from the image right after the data are written and the test-field structure texture uses a salt (15382117) that exists only in tests/gold_gen.py; (b) predicting the DNA channel for every structure - defeated by the explicit dna_copy baseline and by the 0.25 margin of the beats_baselines check; (c) predicting the training-set mean image - likewise defeated; (d) copying the validation targets - the validation split is a separate set of fields, so the format/self_report checks would fail.
- Tool chain: python:3.11-slim with numpy, scipy, scikit-image (disk structuring element, morphology, labelling) and pillow. No GPU and no deep-learning framework is required: the paper's prompt-driven inference is emulated by a deterministic prompt-to-image renderer, which is the only CPU-feasible surrogate at this scale.
- Difficulty: the agent must segment nuclei, convert them into the elliptical nuclear frame, discover that threshold-based radii are ~12 % biased and calibrate that bias against the training split, implement five distinct structure renderers, fit an affine intensity calibration from percentile matching, self-evaluate on the validation split and only then predict - at least four distinct reasoning steps with several iteration cycles.
- Known limitations: the achievable PCC ceiling is set by the radius-calibration accuracy (a perfect geometry recovery gives PCC ~0.95, a 10 % radius bias gives ~0.6-0.8); the similarity metric is masked Pearson correlation on 8-bit grey levels rather than FID, because FID is not reproducible across runs and the paper's supervised/unsupervised comparison therefore cannot be reproduced bit-exactly. The environment has no GPU, so the paper's DPO and self-supervised pre-training stages are out of scope.
