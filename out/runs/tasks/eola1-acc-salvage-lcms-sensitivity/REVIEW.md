# Review notes

- Data substitution: the paper's raw LC-MS and viability workbooks are not public, so all seven input tables were synthesised to be realistic in size and structure (96-well dose-response plates, 12 extracts x 8 MS channels, 6-point external calibration spanning 0-100 nM, 3 biological replicates per condition) and to reproduce the reported phenotypes: free acC rises ~4.3-4.7x in EOLA1 knockouts without changes in other free nucleosides, re-expression restores WT levels, and knockout cells are ~4-5x more sensitive to dipyridamole with the phenotype rescued by cytidine.
- Shortcut probe: the required outputs are computed quantities (channel identities, calibrated concentrations, IC50 values, statistical calls), not labels, so reading the input files cannot reveal the answer; gold numerical values are embedded only in tests/grade.py and are never shipped to the agent. A naive 'annotate by m/z only' strategy is derailed by two isobaric pairs in compound_library.csv (uridine/pseudouridine, N6-methyladenosine/1-methyladenosine) that require retention-time matching, and by a background ion (m/z 312.1444) that must be reported as unassigned. A naive 'report everything as significant' strategy fails because significance requires both BH-adjusted p < 0.05 and |log2 fold change| >= 1, which only the acC knockout comparisons satisfy.
- Tool chain: the image installs numpy/pandas/scipy/statsmodels plus pyteomics, the standard exact-mass library for mass spectrometry; monoisotopic m/z values, ordinary-least-squares calibration, Welch t-tests with Benjamini-Hochberg correction and 4-parameter logistic fits are all recomputed independently inside tests/grade.py with its own atomic-mass table so the grader does not depend on the agent's libraries.
- Known limitations: (1) the input tables are synthetic, so absolute concentration units are internally consistent but not traceable to the original instrument; (2) the hidden gold is the design target of the synthesis, so numeric tolerances (15% for quantification, 25% for IC50) absorb both fit-method differences and authored rounding; (3) the task tests data-analysis competence (calibration, normalisation, statistics, curve fitting, mass annotation), not structural modelling of the EOLA1 ASCH pocket.
