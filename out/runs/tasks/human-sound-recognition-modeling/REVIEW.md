# Review notes

- Data is synthetic and generated programmatically with a fixed seed (42) to mimic the paper's benchmark structure (5 categories, 4 distortions, 1-3 concurrent sources, 4 SNR levels). Real audio was not used due to size and licensing; acoustic features are simulated but the task structure mirrors the paper's human-model comparison.
- Shortcut probe: The generator script is included in the build context but deleted after generating train.csv and test.csv. The agent cannot read the target function. The test targets are regenerated by the verifier from the same protected seed in tests/gold_gen.py. clip_id is random and not a feature.
- Tool chain: Python 3.11, numpy, pandas, scikit-learn, scipy. The reference solution uses a RandomForestRegressor with one-hot encoding and standardization.
- Known limitations: The synthetic features are not extracted from real audio, so the absolute accuracy values are not biologically meaningful. However, the regression task and constraints (correlation, RMSE, MAE) reflect the paper's alignment metrics. The difficulty is calibrated to require >=4 reasoning steps: explore data, preprocess, train/validate, predict, and format output.
