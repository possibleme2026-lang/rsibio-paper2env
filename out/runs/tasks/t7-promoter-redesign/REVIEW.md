# Review notes

- Data substitution: the paper's real 11,588-promoter measurement table and its trained model weights are not public in the input block, so the calculator is replaced by a fully specified deterministic surrogate (position-specific PWM over -17..+6 plus a dinucleotide weight table over the two flanks). All inputs (3000-nt cassette with 8 planted cryptic sites, 1500 held-out 90-nt promoters, 500 noisy benchmark promoters) are produced by the deterministic generator gen_inputs.py (seed 20260801) which is shipped both in the environment and, identically, as tests/gold_gen.py for the grader. Realism is preserved (3 kb cassette, real T7 consensus TAATACGACTCACTATAGGGAGA, 341-codon ORF, GC-balanced flanks, noisy measured rates giving R^2 ~ 0.8).
- Shortcut probes considered: (a) submit the wild-type cassette as the redesign -> cryptic reduction check fails (needs >= 50% reduction); (b) read the gold from the image -> impossible, the reference site lists and the redesign target are only recomputed inside tests/grade.py from the protected seed; (c) tamper with /app/data/model_spec.json -> the grader never reads the environment spec, it rebuilds it from gold_gen.py; (d) randomise the whole cassette -> blocked by the 60-nt total / 82-nt CDS change budget, the protein-identity check, the GC check and the requirement that the canonical 24-nt core stay byte-identical; (e) hard-code the site list -> F1 is recomputed against a list the agent cannot see.
- Tool chain: python:3.11-slim with numpy, pandas, scikit-learn and Biopython (translation, sequence IO). There is no canonical binary for this model (it is a bespoke calculator), so the ground truth is the published parameter file plus the protected reference implementation rather than an external tool.
- Grader: 13 independently checkable constraints, each scored 1/13 (predictions format, prediction RMSE <= 0.05 log10, wild-type site F1 >= 0.90, redesign length, ACGT alphabet, protein identity, canonical core identity, >= 50% cryptic-score reduction, no new strong site, CDS GC tolerance 0.02, change budget 60/82, canonical score >= 0.97x, design_report consistency). test.sh writes {score, reward} to /logs/verifier/reward.json.
- Known limitations: the surrogate model is linear in its features and is not the paper's trained neural/GBM model, so absolute rate values differ from the published 6300-fold-range measurements; the redesign objective is a single-pass greedy synonymous search rather than the paper's generative design loop, but it exercises the same scientific constraints (preserve protein, preserve on-target promoter, minimise cryptic initiation).
