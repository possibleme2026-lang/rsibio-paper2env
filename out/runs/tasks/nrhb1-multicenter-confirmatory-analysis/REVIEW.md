# Review notes

- Data substitution: no raw data accompany the paper, so the entire dataset (216 mice across 3 sites, 144-mouse Western blot subset, 216 x 60-protein DIA panel) is generated synthetically and deterministically by environment/data/gen_inputs.py (numpy default_rng, seed 20260731). The generator is byte-reproducible and the grader holds its own copy (tests/gold_gen.py), so gold is never shipped in the image.
- Shortcut probe: (a) hardcoding the paper's headline p-values (0.076 / 0.533) is useless because the grader recomputes every statistic from the regenerated data; (b) reading gen_inputs.py reveals only the data-generating process, not any of the ~17 required statistics (all of which are sample-specific OLS/pipeline outputs); (c) tampering with /app/data is detected by an md5 comparison against the regenerated reference; (d) guessing the hit counts is blocked because a handful of panel proteins carry non-zero true arm effects, so the significant-protein and |effect|>=0.585 counts are non-trivial.
- Tool chain: the ground truth is classical frequentist inference, so the container installs the canonical Python statistics stack (numpy 1.26.4, pandas 2.2.2, scipy 1.13.1, statsmodels 0.14.2). The grader uses statsmodels' OLS and multipletests(fdr_bh); an agent that implements OLS/BH by hand reproduces the same numbers within tolerance.
- The generator produces the files at image build time (the Dockerfile copies data/ and runs gen_inputs.py), so no large binary blobs are stored in the blueprint.
- Known limitations: values are synthetic, so the conclusion reached on this dataset is not the paper's conclusion; the task targets the reproducibility of the pre-specified analysis pipeline (model specification, missing-data handling, normalisation, multiple testing, formatted output) rather than any specific biological claim. Extreme-case imputation uses global arm-specific min/max, which makes p_best_case and p_worst_case swing strongly; tolerance (2 % relative + small absolute) absorbs implementation-level differences while still rejecting misspecified models.
