# Review notes

- Data substitution: the paper reports a 121-mouse preclinical imaging cohort with no public deposit, so the cohort is synthesised. environment/data/gen_inputs.py regenerates mouse_cohort.csv (5 caliper timepoints, survival_days, event) and pet_ct_roi.csv (body weight, injected dose, ROI volume, mean/max activity concentration) deterministically from seed 20260803; the Dockerfile runs it at build time. The raw PET file stores activity concentrations, so the agent must apply the body-weight SUV normalisation before any modelling.
- Shortcut probe considered: (a) an agent could skip the SUV derivation and regress on raw kBq/mL - the grader recomputes from concentrations and compares Cox coefficients, so this fails; (b) an agent could use the caliper day-14 volume instead of the PET/CT roi_volume_mm3 - the two differ by ~5% lognormal noise and the coefficient comparison separates them; (c) the gold results file never exists inside the image - tests/gold_gen.py recomputes them from the protected seed only at verification time, so no answer key is readable during solving; (d) fabricating plausible-looking JSON is blocked by the self-consistency checks (hr = exp(coef), CI = exp(coef +/- 1.959964 se), lr_p = chi2.sf(lr_stat, df)) combined with a 5% tolerance against recomputed values.
- Tool chain: statsmodels MixedLM fitted with REML=False for the growth-trajectory likelihood-ratio tests, lifelines CoxPHFitter / KaplanMeierFitter / multivariate_logrank_test / logrank_test for the survival analyses, scipy.stats for the chi-square, normal and Mann-Whitney computations. All are installed in the image; the grader calls the same canonical implementations rather than re-implementing them.
- Known limitations: the synthetic hazard model is a simplification of the biological process and the resulting p-values do not reproduce the published ones numerically; only relative risk directions and the qualitative narrative (PET/CT volume and SUVmax as the dominant prognostic features) were targeted. The grader therefore compares against the analysis recomputed on the same synthetic cohort rather than against the paper's reported statistics.
- Grading: twelve weighted check groups (schema 0.05, cohort/responder counts 0.08, response medians 0.07, model x day LRT 0.10, responder x day LRT 0.08, log-rank across models 0.08, log-rank across response groups 0.07, KM medians 0.07, univariable Cox 0.15, multivariable Cox + LRT 0.15, concordance 0.05, Mann-Whitney 0.05). Each group returns a fraction so the reward is graded rather than binary; /logs/verifier/reward.json contains only {'score': float, 'reward': float} and the per-check breakdown goes to stdout and /logs/verifier/report.json.
