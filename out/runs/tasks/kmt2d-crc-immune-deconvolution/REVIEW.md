# Review notes

- Data substitution: no TCGA/MSKCC data are redistributed. A deterministic generator (environment/data/gen_inputs.py, seed 20260731) creates a 240-sample CRC cohort (60-gene targeted RNA panel, MAF-like KMT2D variant table, clinical ICI/OS table) and a 60-cell-line cisplatin screen. The generator is COPYed into the image, executed at build time, then deleted so the agent only sees the resulting TSVs.
- Shortcut probe: the gold statistics are never shipped. grade.py recomputes them from /app/data with the exact reference pipeline, so a static answer file cannot pass. Blind guessing of 'direction-only' constraints is defended against by requiring the magnitude to be within +/-0.20 of gold in the direction checks and +/-0.03 in the delta checks. Reading the generator reveals only the qualitative biology already stated in the instruction (immune genes up in LoF, Treg down, cisplatin AUC down) - the realised per-sample statistics still require the full pipeline.
- Tool chain: numpy/pandas/scipy (Mann-Whitney U, Fisher exact), lifelines (log-rank test and CoxPHFitter) and statsmodels are installed from wheels; no domain ground-truth tool is reimplemented by hand - the canonical statistical implementations are called directly.
- Grader: tests/grade.py is ~250 lines, re-runs the 7-step pipeline on the inputs to build gold, and evaluates 10 independently checked constraints (group sizes, three delta-tolerance checks, direction/significance checks, ICI response, survival, cisplatin, schema). Score = passed/10, giving smooth partial credit.
- Known limitations: the cohort is synthetic and the effect sizes are deliberately large so that all ten constraints are statistically clear at n=240; the task therefore tests reproducibility of the analytical pipeline and biological interpretation rather than discovery of a weak signal. Hazard ratio and odds ratio tolerances (+/-0.10 and +/-0.15) absorb minor lifelines/scipy version differences.
