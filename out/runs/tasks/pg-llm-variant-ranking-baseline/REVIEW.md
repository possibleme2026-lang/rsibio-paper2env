# Review notes

- Data substitution: the paper's 276 DMS assays are not redistributable and frontier LLM inference is unavailable inside a container. The six assays (TP53, EGFR, LYSC, CAH2, SPIKE_SARS2, GFP) use real UniProt accessions, protein names and sequence lengths, but wild-type sequences, homolog alignments and variants are synthetic, generated deterministically (seed 20260727) by environment/data/gen_inputs.py, which runs at image build time so ~95 KB of realistic 64x129-330 MSAs and ~1000 variants ship without any inlined gold. The measured dms_score column is synthesised from a hidden per-assay effect model (random substitution cost matrix, per-position sensitivity, Gaussian noise) so it never equals the target rule.
- Shortcut probe considered: the dms_score column is visible for every variant, so an agent can trivially copy it into predicted_score and hit rho=1.0. Constraint 2 (1e-6 agreement with the reference rule over ~1000 rows) and constraint 4 (top-5 by predicted score) both collapse under that shortcut, and the task text explicitly forbids it. A second shortcut, hard-coding the 20x20 BLOSUM62 diagonal, fails because both terms depend on the MSA-derived column frequencies.
- Tool chain: Biopython 1.83 supplies the canonical NCBI BLOSUM62 matrix (Bio.Align.substitution_matrices.load) and is what the reference solution uses; scipy 1.13 supplies the canonical average-rank Spearman correlation used both by the agent and by the grader. numpy/pandas are present for convenience. The grader re-derives the reference scores itself rather than shelling out to a predictor binary, because the ground truth here is the published closed-form scoring rule rather than a third-party tool.
- Grading: six independently scored constraints (format/coverage, score fidelity, wild-type controls, top-5 prioritisation, per-assay Spearman, split aggregation) are averaged, so partial credit is smooth; a correct implementation scores 1.0, an agent that only parses the inputs scores ~0.15.
- Known limitations: (a) the synthetic assays are not real DMS measurements, so the absolute Spearman values are not comparable to the paper's reported rho ~ 0.40 for frontier LLMs; the task grades faithful reproduction of the benchmark protocol, not predictive accuracy; (b) the load-bearing BLOSUM62 lookup is done through the documented Biopython API with a numpy-index fallback, so a future Biopython API change is handled; (c) the grader regenerates inputs into /tmp/gold_inputs so tampering with /app/data cannot move the target.
