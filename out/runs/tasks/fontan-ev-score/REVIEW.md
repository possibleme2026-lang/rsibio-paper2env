# Review notes

- Data substitution: the ovine Fontan cohort is not public, so a deterministic synthetic cohort with the same structure (19 sheep, 58 longitudinal serum sEV small-RNA libraries over 180 miRNAs, paired chemistry/elastography, ordinal fibrosis grade, train/test split) is generated at image build time by environment/data/gen_inputs.py (seed 20260731). The generator is visible to the agent for provenance, but the graded numbers are recomputed by the verifier with its own reference implementation, so knowing the data-generating process confers no advantage.
- Shortcut probe considered: (a) writing label-derived scores into predictions.csv is blocked because the probabilities must be reproducible from model.json + normalized_expression.csv + clinical.csv within 1e-3, and model.json coefficients must match an independent refit on the training split; (b) reporting a hand-crafted 'panel' is blocked because the panel is compared with the reference elastic-net selection; (c) fitting on train+test to inflate the held-out AUC loses coefficient-match credit.
- Tool chain: numpy/pandas/scipy + scikit-learn 1.5.2 (L1 liblinear selection) + statsmodels 0.14.4 (OrderedModel, logit, BFGS) are installed in the image and are also what the grader uses, so both sides see identical numerics; no domain binary is required because the ground truth here is a statistical pipeline.
- Known limitations: the paper's exact miRNA panel and cohort are not reproducible from the abstract, so the selection protocol (filter rule, CPM, L1 spec, C-grid fallback, top-11) is fixed by the task statement to keep the scoring deterministic; the synthetic effect sizes were chosen so that the reference pipeline comfortably clears the AUC bands while APRI/FIB-4 stay in the 0.6-0.75 range seen in the paper.
- The AUC thresholds are graded in bands (full/mid/low) so that a correct pipeline is not punished by Monte-Carlo variation of the synthetic test split (23 held-out samples, 10 moderate+, 5 severe).
