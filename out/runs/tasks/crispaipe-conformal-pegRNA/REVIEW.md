# Review notes

- Data substitution: The paper's PRIDICT Library-1/2 data are not public in raw form here; we generate deterministic synthetic-but-realistic pegRNA libraries with realistic sequence lengths, editing efficiencies, indel rates, and read depths (500-20,000 reads per design) using a hidden Dirichlet-multinomial DGP inside the image build.
- Shortcut probe: The DGP code is not copied into the image (only executed during build). Library-2 outcome labels are regenerated in tests/gold_gen.py with a hidden noise seed not present in the task environment. Whole-simplex regions are blocked by constraint 8 (median area <= 0.25 and 80% of regions <= 0.40). Constant predictions fail the Spearman constraints.
- Tool chain: numpy, pandas, scipy, scikit-learn, biopython, and primer3-py are installed. The Dirichlet regression is fit with scipy.optimize plus scipy.special.gammaln; the canonical crispAIPE PyTorch model is not used because the benchmark-grade reference pipeline must be CPU-only and deterministic.
- Known limitations: The synthetic DGP is a simplified parametric approximation of crispAIPE's transformer likelihood; it preserves the 2-simplex Dirichlet structure and the cross-cell-type calibration transfer problem, but not the full sequence-to-efficiency transformer complexity. The worker should treat the provided sequences as the primary feature source.
