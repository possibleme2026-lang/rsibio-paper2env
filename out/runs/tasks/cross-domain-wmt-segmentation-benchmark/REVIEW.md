# Review notes

- Data substitution: no public dMRI can be redistributed, so the 15 subjects are synthetic but geometrically realistic - 20 benchmark-core tracts plus 4 context tracts rasterised as parametric tubes in world mm coordinates onto a 112^3 / 1.6 mm template grid and onto three genuinely different native grids (96^3 at 1.9x1.9x2.0 mm, 104x88x80 at 1.8x1.9x2.3 mm rotated 4 deg about z, 80^3 at 2.2x2.2x2.5 mm rotated 3 deg about y, each with per-subject affine jitter). Everything is produced deterministically by environment/data/gen_inputs.py (seed 20260730) during the image build; the generator is deleted from the image afterwards.
- Shortcut probe: the gold answer is never shipped - the grader recomputes every metric from /app/data with the same rules. Index-space comparison fails because native grids differ in shape; computing the ensemble in native space, using linear interpolation, or omitting the connected-component filter shifts boundary voxels and is penalised by the ensemble-map macro-Dice check. Reading the generator would not yield the metrics (they emerge from the geometry) and the generator is not present at solve time.
- Tool chain: numpy/scipy/nibabel are the canonical packages for NIfTI I/O, affine resampling (nibabel.processing.resample_from_to, order=0) and 6-connected component labelling (scipy.ndimage.label); the grader uses exactly the same calls as the reference solution, so a correct pipeline reproduces the gold to floating-point precision.
- Known limitations: the tract shapes are parametric tubes, not streamline-derived masks from real tractography; the domain shift is simulated through voxel size/affine differences plus per-model perturbation parameters rather than real acquisition physics; the EWMTS rule implemented here is a simplified, fully deterministic 3-of-4 voting proxy of the paper's ensemble, which is stated explicitly in the instruction. Subject count (15) and cohort sizes (5 each) are small because the data are generated at container build time.
- Grading tolerances: per-row Dice is compared at 0.02 absolute with a mean-absolute-error term, and the ensemble maps are scored by a continuous macro-Dice ramp starting at 0.80, so agents that implement a slightly different but valid nearest-neighbour convention are only mildly penalised, while wrong-space or wrong-method pipelines fail.
